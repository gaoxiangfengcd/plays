Free Random Name Picker Online

Random Name Picker helps you choose one person from a list without bias. Paste names into the box, keep one name per line, and click Pick a Name to get a random result instantly.

Teachers can use it for classroom participation, streamers can use it for viewer prompts, teams can use it for turns, and friends can use it for party games or casual giveaways. It is simple, fast, and works directly in your browser.

How to Pick a Random Name

  1. Paste or type one name per line.
  2. Press Pick a Name to choose one entry randomly.
  3. Copy the result or pick again from the same list.
